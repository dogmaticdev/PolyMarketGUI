# PolyMarketGUI
A GUI/market finder for PolyMarket. I made this because the PolyMarket website UI sucks ass and its impossible to search for specific markets. This pretty much allows you to use every single search filter available in the API, and its not a slow piece of shit.

# Missing Features
I intended to add database support, aka, something that saves your past markets and let you check up on them, but I never got around to it.
